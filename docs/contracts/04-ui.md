# Contract 04: gebruikersinterface (fase 1)

Lees eerst `00-conventies.md`.

## Pagina: `index.html` (maakt: UX/UI)
- Moet blijven laden: `<script type="module" src="/src/main.js"></script>`.
- Bevat een leeg element `<div id="ui"></div>` boven het canvas, over het hele scherm, `pointer-events: none` behalve op knoppen.
- Laadt `src/ui/styles.css` via een `<link>`.
- Titel van de pagina: "Throttle Rush". Taal: Nederlands.
- Het 3D-canvas wordt door `main.js` aan `<body>` toegevoegd. Het canvas moet het hele scherm vullen zonder scrollbalken.

## Snelheidsmeter: `src/ui/HUD.js` (maakt: UX/UI)

```js
const hud = createHUD();          // zet zichzelf in #ui
hud.setSpeed(kmh);                // elk beeld, getal (kan negatief zijn bij achteruit)
hud.setSurface(surface);          // "road" | "curb" | "dirt" | "grass"
```
- Snelheid groot rechtsonder, in km/u, afgerond.
- Ondergrond klein eronder in het Nederlands (asfalt, berm, aarde, gras).
- Moet bij 60 beelden per seconde goedkoop zijn: alleen de tekst wijzigen als het getal verandert.

## Uitleg besturing: `src/ui/controlsHint.js` (maakt: UX/UI)

```js
showControlsHint();
```
- Een klein paneel linksonder: pijltjes of WASD = rijden, spatie = speciale knop, R = terug op de baan.
- Verdwijnt vanzelf na 8 seconden of bij de eerste toetsdruk, met een zachte overgang.

## Stijl: `src/ui/styles.css` (maakt: UX/UI)
- Kleurrijke, speelse arcade-stijl die past bij low-poly cartoon. Goed leesbaar op elke achtergrond (schaduw of donkere achtergrond achter tekst).
- Lettertype: mag via Google Fonts in `index.html`.
- Werkt op laptopschermen van 1280 x 720 en groter.
